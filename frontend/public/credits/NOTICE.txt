The **About this project** button on the dashboard and editor provides foundation
credits and a searchable component inventory. `frontend/public/credits/components.json`
records locked npm packages, installed Python distributions, Debian api/db packages,
Alpine web/redis packages, foundation runtimes, and optional tools. Its `notice` hashes
reference full texts in `notices.json`. These are package metadata and collected
copyright notices, not a replacement for upstream license terms or matching sources.
Optional platform npm dependencies are listed even when not installed on this host;
their full notices are available in their upstream distributions. Container package
versions reflect the inventory snapshot. External model weights, host packages, Docker
Desktop, and proprietary provider terms are outside the bundled inventory.

Refresh after installing frontend dependencies and rebuilding/starting Compose:
`python3 scripts/generate_credits.py`. Commit the generated metadata and notices,
then rebuild the web image to publish them. The generator verifies the backend
lockfile against the installed Python versions. It reads no project/media/credential
data. Foundation entries should be reviewed when runtime image pins change.

If redistributing container images, retain upstream notices and comply with each
component's source-distribution obligations. Matching Debian sources are available
through Debian's source repositories (`apt-get source` with deb-src enabled).
